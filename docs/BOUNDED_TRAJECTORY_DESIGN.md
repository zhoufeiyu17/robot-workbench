# 有界轨迹构造与翻译层收口方案

2026-11-16。用户已确认设计及 20 ms 性能方案。MODEL 后端实现完成，并通过 SDK 输出关闭的实际模型验收。Claude Fable 5.2 架构与性能各完成四轮有效评审，原型和实现证据分别保留。各目标的实际部署和资格以对应任务回执核验。一次澄清轮超时，其输出未用于结论。项目当前接口真源为 [工作台集成接口](WORKBENCH_INTEGRATION_INTERFACE.md) 和架构目录；本文记录候选决策、证据和验收边界。

## 推荐决策

零边界 MODEL 轨迹采用一次全节点 Bernstein 位置认证、有界局部重定时和一次全局时间延长。合法目标的可规划性由构造及证明保证，最终检查负责识别实现缺陷。正常域内的拟合过冲和迭代预算耗尽不再归为模型预测失败。

完整翻译层交付还须收口原生执行一致性与固定总时长制动的可行域。解析曲线通过不能代替这两项验收。

## 当前链路及证据层

| 层 | 当前职责 | 本方案需要闭合的判断 |
|---|---|---|
| Workflow | 模型、校准、原始观测引用、执行前缀和冻结策略 | 模型输出、转换、规划、预算和执行各有明确原因 |
| InferenceRunner | 工作线程预测、投影、CPU 准备及模式控制 | 捕获原始与采用值，保留当前会话和 epoch |
| motion_reference | 连续 q/v/a、极值、重定时和 Brake | 零边界合法输入获得有限可行参考 |
| TargetInterpreter | 固定格点、事件、原生窗口和撤销 | 保留同一参考时间基及已提交前缀 |
| SDK worker / native | 执行上下文、逐臂时钟、提交及输出 | 执行的曲线、时钟和校验证据与上游一致 |
| MEM / 录制 / 监控 | 真实逻辑进度、原始数据和诊断 | 点采纳、原生输出与实测到位分别记账 |

当前同步 MODEL 从已完成的零 v/a 参考末端或显式 HOLD 开始。原始模型点保留，采用点按既有策略投影；关节使用配置声明的 99% 范围，夹爪使用真实校准 SDK 边界。测量和命令属于不同证据，投影锚点时保留测量原值。

“精确过点”指解析参考及准入数据保留选定节点及其顺序。原生循环不一定恰在任意源时刻发出一帧，实测到位还受跟踪误差影响。MEM 使用已定义的真实采纳/完成时间证据，原始预测数组长度不能代替已执行步数。

## 可规划性契约

新保证适用于显式选择新曲线策略的零边界 MODEL 请求。

- 节点数和形状满足已绑定模型/来源契约，包含合法初始锚点。
- 转换后的节点、限位和校准数值有效，采用点均在真实 SDK 命令范围内。
- 首末 v/a 为零，源时间有序，速度、加速度和夹爪速度限值为正。
- 输入及计算处于声明的可表示数值域，所需执行时长可用有限数表达。
- 允许延长执行时间。episode 剩余预算在规划后单独判断。

这类输入必须返回有限参考，满足解析关节 C2、位置范围、速度和加速度上限，以及校准后的夹爪速度上限。预算不足返回明确的预算原因并进入 HOLD，完整运动段保留其语义。

现有非零起点纯 CPU 调用保留其明确契约及回归。新保证的零边界前提不能成为拒绝所有旧调用的理由。Raw 回放、冻结研究路径和点动各按其已声明的几何、时间与初始状态契约分派。

有限输入与正限值本身不保证浮点时长可表示，例如极小速度可能导致时长溢出。数值域检查和 `numeric_unsupported` 必须明确，配置事实来自实际能力和单位契约，不能按机器编号添加特例或凭空设置拉伸比阈值。

## 按构造保证位置范围

先取当前拟合的节点 q/v/a 作为希望保留的导数，以原始节点时间基作为不可变基准。一个宽度为 h 的五次段具有以下 Bernstein 控制点。

```text
P0 = q0
P1 = q0 + h*v0/5
P2 = q0 + 2*h*v0/5 + h²*a0/20
P3 = q1 - 2*h*v1/5 + h²*a1/20
P4 = q1 - h*v1/5
P5 = q1
```

控制点全部位于 SDK 范围内时，整段曲线位于该范围内。每个节点、每个轴的约束可独立处理。收集该节点对左右相邻段产生的四个控制点偏移 d，并求一次共同缩放。

```text
λ = min(1,
        所有 d>0 时的 (upper-q)/d,
        所有 d<0 时的 (q-lower)/(-d))
(v,a) <- λ*(v,a)
```

合法节点下 λ=0 是可行见证。左右段使用同一节点导数，保留节点 q 和 C2 连续性。只重建受影响的轴/段，其余原系数直接保留。首末零 v/a 属于固定边界。

默认认证域选真实 SDK 范围。按相邻端点范围认证属于另一种更强的保形政策，会在换向或平台处约束该轴导数；它并不等于整机逐点停顿，但本轮不采用它作为默认。速度优先投影也有可行闭式解，本地试验显示它偶尔增加节点加速度；共同缩放更简单，且节点 |v|、|a| 只减不增。

Bernstein 条件是充分条件，可能改动实际曲线尚未越界、但控制多边形越界的近边界段。因此不能宣称全部历史系数零回归或完全没有微停。真实 SDK 范围内仍可能有超过相邻节点范围的摆动，运动质量需通过语料和后续跟踪鉴定。

## 重定时的固定不变量

令原始段宽为 h，延长比例为 r≥1。每个内部节点使用相邻段比例的最大值 s，并始终从已经认证的原始导数取 v/s、a/s²。对某段该节点，ρ=r/s≤1。

```text
P1_new = (1-ρ)*q + ρ*P1
P2_new = (1-ρ)²*q + 2ρ(1-ρ)*P1 + ρ²*P2
```

右端控制点有相同形式。它们仍是界内点的凸组合，故原始基准认证在后续局部重定时下保持。中间重定时结果不能替代原始基准。

局部重定时最多运行 K 轮，K 是经热基准确定的内部算法常量。随后冻结已认证几何，计算一次统一延长比例。

```text
σ = max(1,
        最大关节速度比,
        sqrt(最大关节加速度比),
        校准后最大夹爪速度比)
```

全部时间乘 σ，系数按时间幂次换算。零边界下这是同一几何曲线的时间重参数化，速度和加速度分别缩小为 1/σ 和 1/σ²。K 影响效率和时长，不承担收敛或正确性保证。

最终位置、过点、C2 和动态认证继续存在。20 ms 补充方案将热路径动态求根替换为充分上界证书，独立连续极值核对放到离线验收。认证后的正常域请求仍检查失败时，记录 `internal_fault`，冻结输入和证据。未知异常、撤销、无效输入和未知提交结果不能触发继续下发的保底轨迹。

数值比较复用按单位定义的绝对/相对容差，审计现有曲线检查中的散落字面量。最终数值舍入沿用 G18 容差后投影到同一硬界的路径，并保留原值和采用值。该投影只处理数值误差。

## 原生执行一致性

已读到的当前 native 实现只准入 linear 插值，对 q、dq 分别线性插值，状态向量为 Eigen double。解析曲线的 C2 与加速度证书不能直接作为原生位置序列或物理到位的证书。

已运行的理想 CPU 反例为解析 q(t)=0.5*40*t²。100 Hz 节点位置为 [0.002,0,0.002]，原生线性插值在中间 200 Hz 时刻给出 [0.001,0,0.001]。位置二阶差分为 80 rad/s²，独立 dq 通道差商仍为 40 rad/s²。Fable 已撤回“原生帧位置离散加速度≤解析 A”的判断。新增的其他松上界未经本地核对，不进入资格承诺。

当前 bound-policy 桥对部分规划动态偏差采用 `record_only`。第一批增量须明确标识“观察未强制”，按窗口内、当前输出边界及跨参考边界分类。该状态不能作为翻译层动态约束已经完整落实的结论。

需要一致连续原生参考时，候选协议传递原始完整多项式段、原始 t0/h、参考身份、epoch 和有效求值范围。原生在原始归一化时间上求值，并从同一多项式计算 q/dq/ddq。位置控制点、动态证书及软件构建身份应能对应核验。

- 窗口裁切只改变有效求值域，不能把微秒残段重新归一化拟合。
- 保留原始 source break 和夹爪事件。
- 核对并冻结或校验跨 commit 的逐臂时钟映射。单窗共同偏移误差和节点独立误差分别建模，不能全部当成独立抖动相加。
- 未发出的参考数据和授权执行窗口分开核验；有限队列、授权 horizon、lead、epoch 和撤销继续生效。
- 双臂部分接收和未知提交结果继续走明确保护。只有能证明两臂均未提交的拒绝，才可能允许一次重新建立未来窗口。
- 不启用现有未资格 cubic 分支。命令量化和物理跟踪属于独立证据层。

具体序列化布局、一次/每参考校验的成本及新协议 ABI 在实现设计中核对。对外新增保证前必须关闭相应 `record_only` 缺口，并用原生实际语义验证门槛。

## 固定总时长制动的已知缺口

当前 T=0.2 秒和制动 V/A 与规划策略绑定。请求先保留已承诺前缀，再构造特定制动多项式。该多项式失败走 motion_fault 是代码事实，不能称用户已经接受所有此类失败。

本地 CPU 见证使用 q0=0.9、v0=0.9、a0=20，位置界 [-1,1]、V=1、A=40。

| 构造 | 最大位置 | 最大速度 | 最大加速度绝对值 |
|---|---:|---:|---:|
| 当前固定 T=0.2 的 quartic | 1.056666667 | 1.324538689 | 20 |
| 40 ms quintic 到 q=0.92、v=a=0，再保持 160 ms | 0.92 | 0.935743148 | 38.822474988 |

第二行总参考长仍为 0.2 秒且 C2，证明特定制动公式失败不等于固定总长内物理无解。它只是一例存在性见证，不能证明所有运行状态可制动。更早停止也会改变内部速度形状和峰值减速度，语义和硬件资格需明确。

后续方向是固定总长 T 的“运动段 τ 后保持至 T”族。可先验证当前公式取 τ≤T 的扩展，自由终点 quintic 可作进一步研究。有限候选 τ 表可提供有限计算和覆盖改善，但不能作为全域完备性证明。候选耗尽应称 `brake_family_exhausted`，不能称物理无解。

完整收口还需对实际可提交边界进行离线扫描，给出位置/V/A 分因、修复族覆盖和剩余证明义务。提前到零后保持的内部形状变化待明确确认；运行到原轨迹终点、改变总时长或恢复整段保守 reserve 均不属于本候选。

若新增制动内部断点，须审查 `prefix_then_normal_brake` 的断点数量、wire 上限和最坏前缀长度。新增保持段不增加 MODEL 源步数。

## 独立诊断与原因分类

视频开关独立于小型轨迹诊断。复用既有请求号、执行上下文、policy_hash、reference_id 和构建清单；不为相同语义再增加一套身份。

| 内容 | 用途 |
|---|---|
| 原始/采用节点、初始 q/v/a、单位和能力边界 | 重放转换和构造，辨认输入与规划错误 |
| 容差、原始时间基、λ、r/s、K、σ | 复核位置证书、时间变化及数值问题 |
| 原始观测引用、epoch、请求及策略/代码/依赖身份 | 防止旧会话、旧模型和版本混用 |
| 失败阶段、轴、区间、极值和上限 | 给出明确原因 |
| 准入/逐臂接收/输出证据与时间不确定度 | 区分规划、传输、执行及反馈 |

大数组放有界诊断环和异步故障载荷，热状态只传必要摘要及引用。保留既有 CPU 请求/输出大小限制；落盘、编码和重放均离开 Owner tick。写入失败显式计数并保护最新故障的内存证据，沿既有存储权限管理磁盘。

原因至少区分模型响应、转换/投影、几何认证、重定时、数值域、episode 预算、原生准入、反馈及内部故障。正常规划不再借外层 `prediction failed` 混淆所有阶段。

当前已执行的原型证据包括主选构造 256 例、额外不变量 40 例，以及 256 例算法质量对照。额外用例覆盖 2/3/17/33/61 个节点、零宽度范围、边界锚点、随机局部延长和夹爪单位斜率。它们验证原型数值与公式，不是生产实现资格。

必须纳入确定性回归的反例和变换有边界平台、重复点、单点执行前缀、非对称范围、原始时间基切换、全局时间伸长、取消/旧 epoch、预算不足、部分准入及载荷重放。热进程池记录 p50/p99/max、改动节点数和实际时长比；冷 import/测试断言耗时不能宣称生产延迟。K 和测试预算根据实测确定，无额外线上双算或百万随机样本硬门。

本轮原型无法补回真实失败段的具体关节与超限量。该事实与上述机制反例始终分开。

## 20 ms 性能补充方案

2026-11-16。Owner 为本项目翻译层，父路由为本文及既有架构目录。本节完成 Claude Fable 5.2 四轮性能评审，用户已确认实施。后端候选及十个真实 episode 的两组环境验收均通过，详细结果见本节末尾的实现记录。

### 计时范围与通过条件

主指标使用同一目标机的 monotonic_ns 墙钟。T0 为模型 client 返回已解码响应、开始 epoch、身份、形状和有限性检查之前。T1 为不可变参考与 metadata 已准备完成，全部必需校验、单位转换、父侧排队、CPU 进程往返、数组重建、reference wire、录制与诊断入队完成，并向消费者发布 ready 之后。

GPU 推理、图像/输入解码、模型传输解码、异步落盘、Owner 下一 tick 等待、准入和窗口采样分别报告。本指标的终点为 consumer-ready。新策略的服务就绪前完成全路径 CPU 预热，首个正式请求计入主指标。

最终验收要求每个实际响应的后处理尝试均不超过 20,000,000 ns，并且十个 episode 功能全部通过。p50/p95/p99 用于描述分布，max 与超限次数用于判定。测量分辨率单列，20 ms 截止语义按离散时间检查。模型失败没有后处理耗时，保留为推理失败且整轮资格不通过。

### 已核对的性能卡点

| 项目 | 当前源码事实 | 方案中的处理 |
|---|---|---|
| 局部重定时 | 最多 33 轮全段动态/位置极值计算，首轮与此前计算重复 | 固定一次局部 pass，随后统一延时 |
| 求根 | 批量 companion eigvals，五次段含四次位置根；每轮重复 | 热路径改用位置与动态充分证书 |
| Python 循环 | 受影响段逐段 Hermite 重建，两处 C2 检查 | 批量重建，保留一次必要的连续性检查 |
| CPU 首调 | worker initializer 仅导入 SciPy，完整依赖和路径尚未预热 | 绑定完成后 CPU 全路径预热，再报告 ready |
| 数据搬运 | 请求/返回 JSON、tolist、冻结数组和录制 deepcopy | 全部计入，分阶段实测后决定是否还需改变传输 |
| 父侧调度 | query 与 Owner 同进程，父侧 Python 工作有 GIL 开销 | 保留计算隔离并统计父侧开销 |

各项当前耗时占比尚无最新目标机证据。reference_read 的标量求根发生在 Run 初始绑定阶段；每段 live 轨迹通过同进程 PreparedReference 和队列流转。模型到 device、device 到 SDK 的两次映射各有契约，源码没有证实重复 SDK 逐点转换。

### 唯一默认候选

固定 K=1，N=32。N 表示每段 32 个等距小区间、33 个采样点。MODEL 上限为 60 段、12 个关节轴，每次动态认证最多 720 行。夹爪继续按校准后独立线性速度契约认证。

1. 拟合一次，保留原始节点 q/v/a/h，并完成共享节点导数的 Bernstein 限幅。
2. 动态认证①后进行一次原始基准局部重定时，受影响段批量重建。
3. 动态认证②给出上界，计算统一延长比例并写入最终系数/时间。
4. 在最终存储系数上独立完成动态认证③、位置、节点和 C2 核对。
5. 浮点缩放后的动态证书需要额外余量时，最多再做一次统一延长及认证④。修正比例大于 1 时沿用既有 1.02 时间裕度。实际附加比例为修正比例乘 1.02，逐请求披露。位置、节点、C2 或身份错误直接保留故障。

热路径求根次数为零，动态认证通常三次、最多四次。K=0、N=16 仅保留为取得实测后的重新评审候选。现有非零边界 CPU、Raw、研究、Stop 和 native 契约继续按各自策略处理。

### 固定网格的动态证书

对归一化时间 u∈[0,1] 上的物理速度或加速度 f，计算采样值与曲率上界。固定网格的线性插值误差不超过 M2/(8N²)，其中 M2 覆盖 max|f''(u)|。

```text
U = 向外上界(max_grid |f_hat| + E + M2/(8N²))
L = max(0, 向下界(max_grid |f_hat| - E))
σ_U = max(1, U_V/Vlimit, sqrt(U_A/Alimit), jaw_ratio_upper)
σ_L = max(1, L_V/Vlimit, sqrt(L_A/Alimit), jaw_ratio_lower)
```

规划使用 U，L 用于披露证书保守度。σ_U/σ_L 的分母至少为 1，比较对象须为同一几何和时间状态。相对旧多轮重定时的总执行时长变化另用相同模型输出的离线重放分析。

误差契约以最终 float64 存储系数和 breaks 定义的实多项式为认证对象。h 的差值先向外包围。若物理系数按升幂记为 c，则第 r 阶物理导数归一化后的系数为下式，r 为 1 或 2。

```text
a[r,k] = (k+r)!/k! * c[k+r] * h^k
```

限定次数的小数组区间运算覆盖差值、整数乘法、h 幂、求导与归一化。33 点网格使用普通向量化 Horner，其 E 由标准 γ_(2d) 前向误差界、系数区间半径与显式下溢绝对误差组成。上界组合和正数求和也须覆盖各次舍入，单独对最终结果 nextafter 一次不能替代误差传播。

V 的 f'' 次数至多为 2，A 的至多为 1。M2 使用以下固定 Bernstein 转换，全部输入和小数组运算均向外包围。

```text
二次 a0+a1*u+a2*u²  ->  [a0, a0+a1/2, a0+a1+a2]
一次 a0+a1*u        ->  [a0, a0+a1]
```

位置控制点从最终实际系数重建。证书误差与既有集中命令数值容差同源、同单位，且不大于 G18 的相应容差。解析位置保证包含该纯数值容差，下发采样沿既有 G18 投影到同一 SDK hard box，并保留投影前后值。节点和 C2 独立核对。消费端时间偏移与 native 时钟误差仍按各自契约验收。

上述逐式误差推导、实际存储的降幂索引对应关系、零值/重根/边界/尺度及下溢处理属于实现中的必需核验。构造的可规划保证覆盖声明的可表示、可认证域。区间非有限、溢出或数值域失效归 numeric_unsupported；全部有限但认证④仍失败归 internal_fault。故障参考保留证据并停止下发。

独立算术例为 q=10u³−15u⁴+6u⁵、N=32，V 上界 1.8896484375，真峰 1.875；A 上界 5.811767578125，真峰约 5.773502691896258。V 上界高约 0.78125%，A 上界高约 0.66277%，加速度主导时对应额外延长约 0.33084%。该例验证一条公式，真实产物的保守度仍待测。
